# 助手

助手是管理后台中的聊天窗口，背后是你用自己的 API 密钥连接的云端模型。你可以问它哪些节点出了问题、某人为什么无法连接、谁超过了设备数量限制；也可以让它创建分组、修改订阅文字，或为某个节点关闭一个配置。它使用面板自己的工具查询数据，并把每项更改准备成一张用面板自己的措辞写成的卡片。**在你点击“应用”之前，不会有任何更改。**

它以与之对话的管理员的权限运行，不会更多，并且可在 VPS 版中使用（参见[在 Cloudflare 版中](#在-cloudflare-版中)）。

## 开启

所有者在 **AI → 助手** 中设置：

1. 在**提供商**下，对某个提供商选择**连接**，粘贴其 API 密钥，然后选择**检查并保存**。面板会要求你的通行密钥或验证码，向提供商检查密钥并将其密封；此后卡片上只显示密钥的最后四位。
2. 在已连接的卡片上选择**模型**（每百万令牌的价格显示在其下方）和**每月预算（美元）**。
3. 在上方开启**助手已开启**，选择**聊天使用的提供商**、**思考深度**（**快速**、**普通**、**深入**）、**谁可以使用**（**仅我自己**、**所有者和助手管理员**、**面板中的所有人**），填写**给助手的备注**，设置**保留对话**的时长，然后选择**保存**。

对于可以使用助手的管理员，每个页面的角落都会出现一个圆形按钮；也可以用 **Ctrl+J**（Mac 上为 **⌘J**）打开和关闭聊天。

## 提供商与数据去向

| 提供商 | 面板调用的地址 | 模型 | 数据去向 |
|:--|:--|:--|:--|
| Anthropic | `api.anthropic.com` | 来自提供商的列表；默认 Claude Opus 5.5，Sonnet 5.5 和 Haiku 5.5 更便宜 | 在美国处理；API 数据不用于训练。 |
| DeepSeek | `api.deepseek.com` | 来自提供商的列表 | 存储在中国；提供商的政策允许用你发送的内容进行训练。 |
| Z.ai | `api.z.ai`（国际平台） | GLM-5.3 和 GLM-5.3-Flash | 在新加坡处理；提供商协议称不存储内容。 |
| Ollama Cloud | `ollama.com` | 支持工具调用的云端模型 | 在美国处理；不用于训练。 |

每个内置提供商的卡片上也写着同样的内容。所有者还可以添加最多五个兼容 OpenAI 的自定义提供商：填写名称、API 基础地址（例如 `https://example.com/v1`）、模型 ID、密钥，以及可选的输入和输出价格。保存前，面板会检查模型能否调用工具。如果提供商提供模型列表，也可以从列表中选择。请在卡片上设置每月预算；自定义提供商可以作为主提供商或备用提供商。

面板从自己的服务器调用提供商；密钥会加密保存，不会返回给浏览器。自定义地址必须使用 HTTPS。若要使用面板本地网络中的 HTTP 地址，须明确允许本地访问；本地模型可以不填密钥。链路本地地址（包括云元数据地址）会被阻止；运营商级 NAT 地址（100.64.0.0/10）视为本地地址。选择提供商时请了解其数据政策。填写的价格用于估算费用：只有免费提供商才应使用零价格。

提供商会收到：对话、助手的指令、你的备注和所有者的备注，以及它所调用工具的结果。这些结果会经过与 [MCP](../reference/mcp.md#智能体永远无法获取的内容) 相同的过滤：没有订阅链接和页面密码，没有密钥、设备配置和令牌，没有服务器密码，没有节点地址。如果你输入的消息看起来像密钥或密码，聊天会在发送前询问你。

## 它能做什么

- **读取**：节点及其健康状况、用户、分组、设备、事件和告警、从国家视角的可达性、订阅和 DNS、更新；所有者还可读取审计日志。这些是你的角色可用的 [MCP](../reference/mcp.md) 读取工具。
- **更改**：每一项 MCP 更改都以计划的形式提出。计划会以**建议的更改**卡片出现在聊天中，包含面板自己的摘要、事实（凡来自数据的内容都会被引用）和风险提示。**应用**会且仅会执行这份计划一次；**忽略**会放弃它；10 分钟内未应用的计划会过期。
  - 需要所有者的计划（它会更改节点上运行的内容、涉及很多用户，或每个人都会看到）：所有者与助手对话时，**批准并应用**会要求通行密钥或验证码，并一步完成批准和应用；对其他人，卡片会说明该计划正在 **AI → 等待你处理** 中等待所有者。
  - 通过 SSH 安装节点只能在 **AI → 等待你处理** 中批准，所有者在那里核对主机密钥并选择面板如何登录。
- **它的权限就是你的权限**：所有者的助手拥有管理员工具，协作者的助手拥有操作员工具，只读管理员的助手只有读取工具。

模型自己不会应用任何内容：它没有这样做的工具。每次调用都会在审计日志中记为“<管理员> 的助手”，来源为**助手**（可在 **设置 → 审计** 中按它筛选）。

## 排查哪些连不上

直接问「谁连不上，该怎么修？」，或在 **健康 → 人员** 点击 **排查哪些连不上**：聊天会带着现成的问题打开。助手先调用 `access_report`：按协议与节点（及分组）列出过去一天谁尝试过、谁连上了，以及计数器能区分的拒绝、卡顿、冻结和丢包，还有分配了服务器却从未连接的人。再加上来自该国的视角（哪些运营商看到节点不通、哪些 TSPU 端口被切断、kl!ck 用户看到了什么）和 `block_diagnosis`，说明节点是怎样被封的：地址被封、单个端口被切、TCP 被限速、UDP 被切、某个协议被识别、移动网络只放行白名单地址，或者根本没被封而是节点自己坏了。

回答是按协议、节点和分组的简短概况，加上三到五条按排名给出的建议，每条都附证据并以一个计划提出（经人们能访问的入口做中继、迁到 443 端口、给某组换协议、CDN 配置、IPv6 入口、把被封的服务器从订阅中移除）。规则是固定的，相同的事实得到相同的结论；缺少信号时它会如实说明并指出能给出答案的检查（例如在该国节点上做 UDP 的 `path_probe`）。VLESS 没有尝试计数器，其故障只能通过国家视角和 kl!ck 看到。

## 记忆

- **备注。** 助手会保存它应当记住的内容（聊天中的“已记住：…”，并带有**忘记**按钮）。**AI → 记忆** 会列出这些备注：可以添加、编辑和删除任意一条，或选择**全部忘记**。每条备注都会进入每次对话；最多 100 条，每条最长 400 个字符。
- **给助手的备注**（所有者在 **AI → 助手** 中填写）：每位管理员的助手都应了解的关于此面板的信息。
- **对话。** 助手知道你最近对话的标题，当你提到更早的对话时，它可以搜索并阅读。**AI → 记忆 → 对话** 可在聊天中打开某个对话，或删除一个或全部对话。

对话和备注在面板的数据库中被密封，并且只属于各自的管理员：其他人都读不到，包括所有者。对话的保存时间由**保留对话**决定；备注会一直保留，直到你删除。面板发送给提供商的内容中，任何看起来像密钥或密码的字符串都会被删去，你自己输入的消息除外。

## 限制与费用

- 一次回答最多使用 24 次工具调用和 10 分钟；**停止**会立即结束回答，并保留已经说出的内容。
- 每位管理员每分钟最多发送 20 条消息，同一个对话一次只生成一个回答。
- 每个提供商都有所有者设置的**每月预算（美元）**，根据提供商的价格和每次回答报告的用量估算。达到预算后，助手会停用到下个月。**AI → 助手 → 本月** 会显示每位管理员的费用。

## 安全

- 密钥用面板的主密钥密封，所有者通过通行密钥或验证码后输入主密钥；密钥永远不会显示，也不会写入日志或审计日志。
- 节点和用户的名称、备注和日志行对助手来说是数据，而不是指令；它没有可以访问互联网的工具；聊天不显示图片和 HTML，指向管理后台页面的链接留在管理后台内，其他链接会单独打开。
- 即使节点名称或备注诱使模型提出了某个建议，那也只是一张卡片：只有当有人阅读并点击**应用**之后，更改才会发生。

## 定时回访

助手会回答你的消息，也能自己回来。当它启动或准备一件稍后才结束的事（节点的调试日志采集、测速、结果稍后才出的检查、发布或节点更新、中继）时，它会设置一次定时回访：时间定在任务结束后不久，并附上一条说明，写明到时要读取什么。对话中会出现一行安静的提示，例如「我会在 15:41（9 分钟后）回来告诉你结果 · 取消」，时间按面板的时区显示。

- 到时间后，面板会自行继续同一个对话，浏览器关闭时也一样：助手看到此前的对话，用它的工具读取结果并作答。回答带有 **定时** 标记，聊天按钮和对话列表上的圆点表示它是在你不在时到达的。
- 如果某项更改要等你应用计划后才开始（调试日志采集、测速），定时回访会等到应用后再开始计时；如果你忽略该计划或计划过期，定时回访也会一并取消。
- 它可以读取你的角色能读取的内容，限制和预算相同。由于无人在场，它只准备操作员无需任何人批准就能进行的更改：需要管理员权限或所有者批准的更改，它会请你在聊天中提出。在你点击计划卡片上的 **应用** 之前不会有任何更改。
- 每个对话最多有 3 个定时回访在等待，每位管理员最多 20 个，每个在 30 秒到 24 小时之后。点击该行的 **取消** 可移除它；删除对话也会移除其中的定时回访。
- 当定时回访无法运行时（助手已关闭、本月预算已用完、提供商一直失败），对话中会留下一条写明原因的简短说明。面板停机期间错过的定时回访会在面板再次启动时运行一次，除非已晚了一天以上：这时它会被放弃，并留下一条说明。
- 如果你提出要求（「有问题就在 Telegram 告诉我」），发现问题的定时回访还会向你绑定的 Telegram 聊天发送一行消息。这个要求必须出现在你自己的消息里；助手会在回答中说明是否会发送 Telegram 消息。

## 计划任务

面板可以按计划自行检查各节点，发现问题时通知你：打开 **AI → 计划任务**。所有者创建、修改和删除任务；协助者可以查看并点击**立即运行**；只读管理员看不到它们。

### 两种类型

- **检查**：按顺序运行的一组面板自有工具及其参数，不用模型，也不花钱：`fleet_digest`、`checks_run_now`、针对某个国家的 `block_diagnosis`、两个节点之间的 `path_probe`，以及操作员配置中的其他读取和探测工具。每一步都可以对工具结果设置条件；条件成立即表示本次运行发现了问题。编辑器一键提供常用条件：**有警告或更严重的发现**、**有节点不在线**、**数值超过阈值**、**列表不为空**。字段是结果中用点连接的路径（`totals.nodes_problem_now`、`nodes[].status`，或表示任意深度字段的 `**.severity`）。**工具失败也算作问题**会把没有响应的节点算作问题，而不是运行失败。
- **助手**：按计划交给助手的提示，例如“检查所有节点，有问题就告诉我”。它使用操作员的工具：可以读取、探测，也可以准备计划，计划以卡片形式等待你处理；它从不应用任何更改。它的回答写入该任务自己的对话，在 **AI → 记忆** 和聊天历史中标为**计划任务**，每次运行一个新的部分；你可以打开它，从最近一次运行接着问。每次运行结束时它都会给出结论，由结论决定本次运行是否发现了问题。费用从助手的月度预算中扣除。

你也可以直接请助手来做（“每天早上检查一遍节点，有问题告诉我”）：它会把任务准备成计划，由你批准。外部智能体通过 [MCP](../reference/mcp.md) 的 `task_create_plan` 做同样的事。

### 何时运行

- **每隔** N 分钟或小时（检查任务最多每 5 分钟一次，助手任务每 15 分钟一次）、**每天**某个时刻，或**每周**某天某个时刻，按面板时区计算（与更新计划相同；标签页中会注明）。
- 每个任务会在设定时间之后的几分钟内开始，延迟总是相同，这样任务不会在同一秒同时启动。
- 同一任务同时只运行一次。面板停机期间错过的运行会在面板重新启动后运行一次，而不是每错过一次就补一次；因停机而中断的运行会标为已中断。
- **立即运行**会马上开始一次：检查任务最多每分钟一次，助手任务最多每五分钟一次。

### 运行结果

| 状态 | 含义 |
|:--|:--|
| 正常 | 没有需要报告的。 |
| 有问题 | 有条件成立，或助手的结论如此。 |
| 失败 | 运行没能完成工作：工具没有响应、提供商出错、没有结论；会显示原因。 |
| 已跳过 | 运行没有开始：助手已关闭，或本月预算已用完。 |

发现问题会在**运行状况**中打开告警**计划任务发现了问题**，附带任务名称和简短摘要；后续某次运行正常时它会自动关闭。连续三次运行失败会打开**计划任务持续失败**并注明原因。任务开启**同时发到 Telegram** 时，两者都会发到为告警绑定的聊天。任务下的**运行记录**列出最近 50 次运行（最多 30 天）：每一步命中了什么和结果的开头，或助手的对话及其费用。

### 可靠性

- 没有响应的提供商会被再次请求，间隔逐渐加长；仍然失败时，运行会在你于 **AI → 助手** 中选择的**计划任务的备用提供商**上重新开始。
- 遵守每个提供商的月度预算：会超出预算的运行不会开始，并会说明原因。
- 一次检查运行最多 5 分钟，助手运行在每个提供商上最多 10 分钟；同时最多运行两个检查和一个助手任务。
- 任务中不保存任何机密：看起来像密钥、令牌或带有机密链接的名称、参数或提示会被拒绝，提示像助手的笔记一样密封保存在面板数据库中。

## MCP、令牌与审批

外部智能体（Claude Code、Cursor、你自己的脚本）继续使用 [MCP](../reference/mcp.md) 和 [API 令牌](../reference/api.md)：它们已从“集成”移到 **AI → MCP 与令牌**，等待所有者的计划则移到 **AI → 等待你处理**，菜单中带有角标。**集成** 保留 Telegram 告警。

## 在 Cloudflare 版中

那里暂时不提供助手，MCP 和计划任务也一样：**AI → 助手** 和 **AI → 计划任务** 会说明这一点。它们将与 MCP 一同推出。

## 它没有回答时

| 聊天提示 | 怎么办 |
|:--|:--|
| 提供商不接受该密钥。 | 在 **AI → 助手** 中更换密钥。 |
| 提供商账户余额不足。 | 到提供商处为账户充值。 |
| 该提供商本月的预算已用完。 | 提高**每月预算（美元）**，或等到下个月。 |
| 所有者没有向你的角色开放助手。 | 由所有者修改**谁可以使用**。 |
| 请求过多，请一分钟后再试。 | 等待一分钟；速率由提供商或面板限制。 |
| 提供商没有响应，或已过载。 | 稍后再试，或在 **AI → 助手** 中切换提供商。 |
