---
title: 用户与分组
description: 如何创建和管理用户（配额、有效期、流量、设备和访问权限）、分组的作用，以及如何在分组间移动用户。
---

用户是获得访问权限的人。每个用户属于一个分组，分组决定他们可以使用哪些协议配置。此外，每个用户都有自己的限制（流量配额、有效期、设备上限）、应用开关和可用节点选择。**用户**部分包含两个选项卡：**用户**和**分组**。

## 用户可以获得什么

满足以下所有条件时，用户才能使用一台服务器：

- 用户处于有效状态（未停用、有效期未结束、未超出流量配额）；
- 协议配置属于该用户所在的分组；
- 协议配置部署在用户可以使用的节点上（所有节点，或专门为该用户选择的节点）；
- 该节点上的协议配置已启用，且状态为运行中或启动中；
- 用户开启的某个应用开关允许使用此协议。

这些设置发生任何更改后，都会立即下发到节点。

## 两种连接方式

| | 通过订阅链接 | 通过 AmneziaWG 密钥 |
|:--|:--|:--|
| 应用 | 订阅类应用（Happ 和其他读取分享链接的应用、基于 mihomo 内核的应用） | AmneziaVPN 和 AmneziaWG 应用 |
| 协议 | Hysteria2（基于 mihomo 内核的应用也支持 AmneziaWG） | AmneziaWG |
| 用户需要添加什么 | 每台设备使用一个链接 | 每台设备使用独立密钥 |
| 更新方式 | 应用会自行刷新链接 | 手动重新导入密钥 |
| 用户上的开关 | 按订阅类应用名称显示的开关（「Happ」或在订阅设置中指定的应用名称） | **AmneziaVPN** |

这两种方式会并列显示在用户页面上。至少要开启一个开关。参见[订阅](subscriptions.md)、[AmneziaWG](amneziawg.md) 和 [用户页面](user-page.md)。

## 用户选项卡

页眉会显示用户人数和在线人数。列表上方有：

- **名称或分组**：按用户姓名或分组名称搜索；
- **全部**、**当前在线**、**即将到期**（7 天内）和**超出配额**标签，每个标签旁都会显示数量。

| 列 | 显示内容 |
|:--|:--|
| **名称** | 用户姓名；如果用户暂时无法使用任何内容（分组中的协议配置未部署到任何节点，或没有协议配置符合已开启的应用和所选节点），则显示**无访问权限**。 |
| **状态** | **有效**、**已过期**、**超出配额**、**设备上限**或**已停用**。 |
| **应用** | 用户过去 7 天实际使用的应用：**Happ**、**Amnezia** 或 **两者**。 |
| **分组** | 用户所属分组。 |
| **设备** | 已使用设备数和设备上限。 |
| **流量** | 当前周期已用流量，以及与配额对比的进度条。 |
| **有效期** | 剩余天数；∞ 表示永不过期。 |
| **最后在线** | 在线时显示「现在」，否则显示距离上次在线的时间。 |
| **节点** | 最近一次连接所在的节点。 |

**设备上限**不是单独的状态：它表示用户仍处于有效状态，但设备数已达到上限。已停用的用户始终显示**已停用**；之后依次显示**已过期**和**超出配额**。

列表按页显示，每页 50 个用户（也可请求每页 25 或 100 个）：卡片下方会显示「显示第 51–100 条，共 137 条」，以及页码按钮和每页行数。筛选或搜索会对各自的结果分页；页码会保存在地址中。

### 批量操作

勾选列表中的用户（或当前页的所有用户）后，会出现操作栏：「已选择：3」。

- **续期 30 天**会从今天和当前有效期结束日期中较晚的日期起，为每个用户延长 30 天。没有有效期的用户会被跳过：延长操作会给他们设置有效期。
- **停用**会立即停止这些用户的访问。消息中会显示**撤销**，持续几秒。
- **取消**会清除所选用户。

API 还支持在一次调用中启用、删除多个用户并重置他们的流量。参见 [API](../reference/api.md)。

## 创建用户

打开**新建用户**后会显示表单：

| 字段 | 默认值 | 说明 |
|:--|:--|:--|
| **名称** | | 必填，不能重复（不区分大小写），最多 64 个字符。 |
| **分组** | 如果存在「所有人」分组则选中它，否则选中第一个分组 | 下方的**可获得**会说明此分组的用户能获得什么：订阅链接和 AmneziaVPN 密钥，以及部署这些内容的节点数。如果用户将无法获得任何内容，会显示红色提示。**编辑分组**会打开该分组。 |
| **流量配额** | 100 GB | 每次调整 10 GB；设为 0 表示**不限**。按月重置，每月 1 日重置。 |
| **有效期** | 30 天 | 每次调整 5 天；设为 0 表示永不过期。之后访问会暂停。 |
| **设备** | 5 | 范围为 1–100，表示可连接的设备数。 |
| **订阅中的应用** | 分组提供的应用 | 订阅类应用开关和 **AmneziaVPN**。在你更改之前，开关会遵循分组设置：如果分组无法提供某种连接方式，该开关默认关闭，并在下方说明原因。 |
| **所有节点** | 开启 | 新节点会自动加入。关闭后需要勾选节点；之后新增的节点不会自动加入。 |
| **更多** → **DNS** | 继承 | 用户自己的 DNS 预设；留空时使用分组或默认预设。参见[DNS](dns.md)。 |

如果还没有分组，表单会直接显示分组表单。点击**创建**后会创建用户并打开链接窗口；系统会复制链接（如果页面需要密码，也会复制页面密码），供你发送给用户。如果用户暂时无法使用任何内容，链接发送前窗口会说明原因。

GB 采用十进制单位：100 GB 等于 100,000,000,000 字节。

## 用户卡片

页眉显示姓名、状态、应用、分组和有效期（「截至 10 月 12 日 · 14 天」），以及三个按钮：**停用**（或**启用**）、**续期 30 天**（没有有效期的用户无法使用此按钮）和**订阅链接**。

下方的信息条会说明访问受限的原因，并提供快速解决方法：

| 原因 | 信息条 | 按钮 |
|:--|:--|:--|
| 有效期已结束 | 「有效期已于 3 天前结束，访问已暂停。」 | **续期 30 天** |
| 流量配额已用完 | 「100 GB 的流量配额已用完，访问已暂停；配额重置或你调高配额后即可恢复」 | **+50 GB** |
| 设备上限 | 「已达设备上限（5），新设备无法连接」 | **+1 台设备** |

### 流量

显示当前周期的已用流量与配额、重置周期（「每月 1 日重置」）、过去 14 天的图表，以及各节点和协议的流量。

### 设备

计数器会显示已用设备数和设备上限。下方有两个列表：

- **通过订阅**：每台设备上的一行**订阅类应用**会列出所有应用；它们合计占用设备上限中的一个名额。这里会显示应用上次获取链接的时间。**断开连接**会立即断开这些应用；它们会在下次更新订阅时重新连接。
- **AmneziaVPN 密钥**：每台设备占一行，显示设备平台、协议配置和最近连接时间；提供**显示密钥**和**删除**操作。**添加设备**会生成新密钥。**已过时**标记表示设备需要重新获取配置。参见[AmneziaWG](amneziawg.md)。

**删除**会断开该设备，并从所有节点移除它的密钥。

### 订阅页面

**订阅页面上显示的名称**：用户页面向用户问候时使用的名称，最多 64 个字符。留空时使用账户名称；字段下方会显示问候语（「页面问候语：…」）。**保存名称**会保存此名称。任何获得链接的人都会看到这个名称；其他用户设置不会因此改变。参见[用户页面](user-page.md)。

### 每台服务器的 DNS

用户在自己的页面上为服务器选择 DNS 后（参见**页面上的 DNS 选择**），此部分会列出他们在各服务器上的选择（所有管理员均可只读查看）。**重置**会移除所有选择，恢复常规 DNS 规则（用户自己的预设、分组预设、实例预设或节点默认预设）。所有者和协作者可以重置；操作会以 `user_dns_choices_reset` 写入审计日志。关闭此选项不会移除已有选择：这些选择会继续生效，直到你在此处重置。参见[DNS](dns.md)。

### 限制

| 设置 | 步长和范围 |
|:--|:--|
| **流量配额** | 每次调整 10 GB，范围为 0–10000 GB；设为 0 表示**不限**。 |
| **有效期** | 每次调整 5 天，最多 3650 天；∞ 表示**永久**。在 ∞ 上选择「−」会设为 30 天。 |
| **设备** | 每次调整 1 台，范围为 1–100 台。 |
| **限速** | 开启开关后会设为 20 Mbit/s；之后每次调整 5 Mbit/s，范围为 5–10000 Mbit/s。仅供 Hysteria2 实验使用。 |

停止点击后，更改会立即保存。

### 访问权限

- **分组**：选择另一个分组后，服务器会先计算更改并显示结果：「Alice 将失去：『AWG 3.1』（2 个 AmneziaVPN 密钥将停止工作）」、「可获得：…」。点击**更改分组**确认。一个 AmneziaVPN 密钥只属于一个协议配置；用户失去该协议配置后，相关密钥会停止工作。
- 分组提供的协议配置按两种连接方式列出，每个都链接到其页面。
- **DNS**：用户自己的预设；留空时使用分组或默认预设。下方会说明适用的预设及其来源。
- 应用开关。
- **所有节点**或逐节点勾选框。没有适用协议配置的节点会显示为灰色；「仅 Hysteria2」表示该节点只有一种协议。点击节点名称会打开其**协议配置**选项卡，可在那里设置端口和域名。

### 危险区域

- **重置流量**会将当前周期的已用流量设为零。周期及其结束时间不会改变，历史记录会保留；因配额受限的用户可以重新连接。此计数无法恢复。
- **删除用户**会永久移除该用户：从所有节点删除其密钥、断开其连接、停用链接并删除其流量历史。输入姓名以确认。

## 配额周期

在管理后台创建的用户会在每月 1 日（UTC）重置配额。API 还可以设置为每日、每周、每 30 天滚动重置，或不重置；卡片会显示当前设置。周期结束时，已用流量会重新从零开始，因配额受限的用户会自动恢复访问。

## 设备和设备上限

每台设备占用一个名额：

- 用户在所有设备上的订阅类应用合计占用一个名额；基于 mihomo 内核且承载 AmneziaWG 的应用也共用这个名额；
- 每个 AmneziaVPN 密钥占用一个名额。

达到设备上限后，你和用户都无法创建新密钥；订阅链接仍可使用。提高设备上限，或删除用户不再使用的设备。

## 分组选项卡

分组是一组用户可以获得的协议配置。每个分组显示为一张卡片，包含分组名称、成员人数（链接到筛选后的用户列表）、两种连接方式对应的协议配置及其部署节点数，以及分组自己的 DNS 预设（如果已设置）。卡片上有**编辑**和**删除**操作。

如果还没有任何分组，选项卡会提供**创建包含全部协议配置的「所有人」**和**新建分组**。

### 创建和编辑分组

- **名称**，最多 64 个字符。
- **分组包含的协议配置**：新建分组时默认勾选所有协议配置；取消勾选不应提供给该分组的配置。
- **更多** → **DNS**：分组的 DNS 预设；留空时使用实例默认预设。

编辑分组会更改该分组所有成员的访问权限（「此分组有 3 个用户；更改将应用于所有人」）。从有成员的分组中移除协议配置前，会先显示他们将失去的内容，包括哪些 AmneziaVPN 密钥会停止工作；按钮会变为「从 3 人处收回」。

也可以从协议配置页面将配置添加到分组（**加入分组**）。

### 在分组间移动用户

- 移动单个用户：用户卡片 → **访问权限** → **分组**，并查看用户将失去和获得的内容。
- 移动某个分组中的所有用户：删除分组并移动其成员（见下文）。列表不支持批量更改分组。

### 删除分组

- 空分组会立即删除：协议配置保留，只删除分组。
- 删除有成员的分组时，系统会询问要将成员移到哪里（「此分组有 3 人。要将他们移到哪里？」）；如果存在「所有人」分组，则默认选中。点击**移动 3 人并删除**即可一步完成移动和删除。
- 如果没有其他分组，就没有可移动的目标：先创建另一个分组。

## 谁可以执行哪些操作

所有管理员都可以查看用户和分组。所有者和协作者可以创建、更改和删除用户及分组，可以发放链接和密钥，可以为用户和分组选取 DNS 预设，也可以重置用户按服务器设置的 DNS。只有所有者可以选择节点向用户提供哪些预设。参见[安全](../operations/security.md)。
