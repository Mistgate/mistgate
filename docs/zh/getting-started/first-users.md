---
title: 首批用户
description: 从已有一台已连接节点的面板开始，尽快让用户建立可用连接。
---

要让用户获得可用连接，需要准备四项内容：已连接的节点、部署在该节点上的协议配置、包含此协议配置的分组，以及属于该分组的用户。本页按此顺序逐步介绍。假设你已经[添加节点](add-node.md)，无论是手动添加还是[通过 SSH 添加](ssh-install.md)。

## 快速开始清单

在这四项内容准备齐全之前，概览页会显示一个包含相同四个步骤的**快速开始**卡片：

1. **节点已连接**
2. **节点上的协议配置**
3. **带协议配置的分组**
4. **用户和链接**

面板会根据现有内容自动勾选每一步；你无需手动勾选。未完成的步骤有一个按钮可带你前往对应页面，下一步的按钮会高亮显示。全部完成后，卡片会折叠成一行「全部就绪：节点、协议配置、分组和用户」；点击**隐藏**后，该卡片只会在此设备上隐藏。

## 1. 创建协议配置并部署到节点

打开**协议配置 → 新建协议配置**。也可以从节点页面开始：**协议配置 → 添加协议配置**。

1. **协议。** 选择一种：
   - **Hysteria2**，用于订阅类应用：例如 Happ，或基于 mihomo 内核的应用，例如 kl!ck、Clash Verge 或 FlClash。一个链接包含所有服务器。
   - **AmneziaWG**，用于 AmneziaVPN。每台设备都有自己的密钥。如果用户启用了 AmneziaVPN，基于 mihomo 内核的应用也可以通过订阅获取这些服务器。
2. **名称。** 在你输入名称前，它会根据端口自动生成，例如「Hysteria2 · 443」。
3. **设置。** 默认值适合入门。对于 Hysteria2，留意一个字段：
   - **证书：Let’s Encrypt**（默认）需要一个 A 记录指向节点的域名，并且节点开放 TCP 80 和 443。系统会使用节点地址；如果填写了协议配置的**域名（SNI）**，则使用该域名。
   - **证书：自签名**（固定指纹）适用于 IP 地址；应用会检查订阅中提供的证书指纹。

   Hysteria2 使用 UDP 端口 443，默认启用 Salamander 混淆并生成密码。AmneziaWG 协议配置使用 3.1 版本，在随机 UDP 端口上运行并生成混淆设置。
4. **创建后立即。** 页面底部的此区域会依次执行后续步骤：
   - **部署到节点**：你的节点已预先选中。
   - **加入分组**：在新面板上，由于「所有人」分组尚无此协议的协议配置，因此会默认勾选该分组。
5. 点击**创建协议配置**。面板会显示「协议配置已创建，并部署到 1 个节点」。

节点会在几秒内启动服务器。节点的**协议配置**标签页会显示端口、域名（SNI）和证书。节点会在后台获取 Let’s Encrypt 证书；签发后，证书及其到期日期会显示在该页面。

如果选中的节点无法使用 Let’s Encrypt，表单会在创建协议配置前发出警告：「地址是 IP，Let’s Encrypt 无法用于该地址」。此时选择自签名证书，或填写域名（SNI）。详细说明见[协议配置](../guide/profiles.md)、[Hysteria2](../guide/hysteria2.md) 和 [AmneziaWG](../guide/amneziawg.md)。

## 2. 检查分组

打开**用户 → 分组**。设置向导创建了「所有人」分组；如果在第 1 步保留了勾选，协议配置已在该分组中。否则，打开分组，在**分组包含的协议配置**下勾选相应协议配置并保存。从协议配置页面的**部署位置 → 加入分组**也可以完成同样操作。

没有协议配置的分组不会授予访问权限。详见[用户和分组](../guide/users-and-groups.md)。

## 3. 创建用户

打开**用户 → 新建用户**：

| 字段 | 默认值 | 说明 |
|:--|:--|:--|
| 名称 | | 用户在管理后台中的显示名称，例如「Alice」。 |
| 分组 | | 用户从哪个分组获取协议配置。 |
| 流量配额 | 100 GB | 每个周期的流量。0 表示不限。 |
| 重置周期 | 每月 | 每天、每周或每月（UTC 00:00），或从不。 |
| 有效期 | 30 天 | 到期后暂停访问。0 表示永不过期。 |
| 设备 | 5 | 可连接的设备数。 |
| 订阅中的应用 | 分组提供的应用 | 订阅类应用和 AmneziaVPN，各有一个开关。如果分组没有该应用可用的运行中服务器，相应开关会关闭。 |
| 全部节点 | 开启 | 包括之后添加的所有节点。关闭后可自行选择节点。 |
| 更多 → DNS | 分组的预设 | 仅对该用户生效的 DNS 预设。见 [DNS](../guide/dns.md)。 |

点击**创建**。面板会显示「Alice 已创建 · 链接已复制」；订阅链接已复制到剪贴板。

## 4. 发送链接

用户页面有一个**订阅链接**按钮。打开后会显示链接和二维码，并提供**复制链接**、**复制以发送**、**分享**、**打开页面**和**生成新链接**操作。通过私信发送链接；打开后会显示简单说明。

用户需要执行以下操作：

1. 在要用于连接的手机或计算机上，用浏览器打开链接。用户页面会显示该平台的说明、要安装的应用、用于将订阅添加到应用的按钮、供其他设备使用的二维码，以及流量和有效期。如果你在节点设置中填写了服务器的网络带宽，该页面还会显示每台服务器的带宽占用程度（低、中、高）。
2. **订阅类应用：** 安装应用，并按页面上的按钮添加订阅；也可以将链接粘贴到应用中。应用会获取服务器列表，并在之后通过同一链接刷新列表。
3. **AmneziaVPN：** 如果在**订阅 → 用户页面**中启用了**页面上的设备**，用户可以在同一页面为设备生成密钥，并将其导入 AmneziaVPN。如果关闭此选项，则由你在管理后台生成密钥并发送给用户。

如果页面要求密码，说明已启用页面密码；**复制以发送**会将链接和密码放在同一条消息中。每台设备只需输入一次密码；应用无需密码。

如何确认用户已成功连接：

- 应用获取链接后，用户的**设备**列表就会显示相应设备（在此之前会显示「暂无设备，朋友打开链接后会出现」）。发送设备 ID 的应用各占一行，其余应用共用一行。
- 节点页面和概览页会显示用户在线，流量计数也会开始增加。
- 如果链接窗口显示用户「暂时无法获取任何内容」，说明其可用节点上没有运行分组中的协议配置：返回第 1 步和第 2 步检查。

> **注意：** **生成新链接**会立即替换旧链接；任何持有旧链接的人都需要获取新链接。如果链接被转发给了不该拿到的人，生成新链接，并从用户的**设备**列表中删除不认识的设备。
