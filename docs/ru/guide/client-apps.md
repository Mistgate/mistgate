У Mistgate нет собственного клиента. Люди подключаются готовыми приложениями, а панель отдаёт каждому то, что оно умеет читать. На этой странице: какое приложение подходит для какой платформы, что получает каждое, как работает кнопка **Добавить** на [странице пользователя](user-page.md) и как настроить приложения.

## Какое приложение где

| Платформа | Рекомендуем | Ещё предлагаем |
|:--|:--|:--|
| Windows, macOS | [kl!ck](#klck): Hysteria2, VLESS и AmneziaWG в одном приложении | Happ; AmneziaVPN для ключей |
| iOS, Android | Happ: Hysteria2 | AmneziaVPN для ключей |
| Linux | по умолчанию нет | AmneziaVPN для ключей; любое приложение на ядре mihomo, которое вы добавите |

Это список свежей панели (см. [Свежая панель](#свежая-панель)). Его можно менять: приложение можно добавить, убрать, переставить и отметить рекомендованным.

## Что получает каждое приложение

Одна ссылка подписки обслуживает все приложения. Формат панель выбирает по User-Agent приложения (правила вкладки **Подписки → Кому что отдавать**, см. [Подписки](subscriptions.md)).

| Приложение | Формат | Что внутри |
|:--|:--|:--|
| kl!ck | Mihomo YAML (kl!ck шлёт `User-Agent: mihomo/…`, его берёт правило по умолчанию `mihomo`) | Серверы Hysteria2, VLESS и AmneziaWG, одна группа серверов, секция `dns:` из DNS-пресета человека. |
| Clash Verge Rev, FlClash, Clash Meta for Android | Mihomo YAML, если User-Agent приложения содержит `clash` или `mihomo` (два правила по умолчанию) | То же, что у kl!ck. Приложение, под которое не подошло ни одно правило, получит список ссылок: добавьте правило с частью его User-Agent. |
| Happ | Список ссылок (base64) | Серверы Hysteria2 и VLESS: Happ не умеет AmneziaWG. Только Happ получает ещё заголовок `Routing` с DNS-пресетом и загрузку в названиях серверов. |
| Hiddify, v2rayNG и другие приложения этого семейства | Список ссылок (base64), если их не поймало ваше правило | Серверы Hysteria2 и VLESS. Читает ли приложение ссылки `hysteria2://` и `vless://` (REALITY, XHTTP), зависит от его версии. |
| AmneziaVPN, приложения AmneziaWG | Подписки нет: ключ на устройство (`vpn://`, файл `.conf` или QR-код) со страницы человека | Только AmneziaWG. |

Серверы AmneziaWG попадают в приложение на ядре mihomo, только если у человека включён способ AmneziaVPN (**Приложения в подписке** на карточке пользователя или группы), а в группе есть профиль AmneziaWG на ноде. Первое обращение такого приложения за подпиской выдаёт его устройству ключи AmneziaWG. Ядро должно быть достаточно новым: панель называет Mihomo 1.19.30 и новее для AmneziaWG 3.1 и 1.19.14 для 2.0 рядом с каждым ключом ([AmneziaWG](amneziawg.md)).

## Какие приложения сообщают ID устройства

[Лимит устройств](subscriptions.md#лимит-устройств-для-приложений-по-ссылке) считает приложение по ID устройства, который оно шлёт в заголовке `X-HWID`. Приложение с ID получает своё место и свои ключи; приложение без него делит место с другими такими приложениями. В последнем столбце — что видит человек, когда панель отказала устройству ([что показывает приложение](subscriptions.md#что-показывает-приложение-при-отказе-устройству)).

| Приложение | Шлёт ID устройства | Что показывает при отказе |
|:--|:--|:--|
| kl!ck | Да. ID — хеш от идентификатора компьютера и хоста подписки, вместе с системой и именем компьютера. | Только запись-заглушку: объявление оно не читает. |
| Happ | Да, по умолчанию. Человек может выключить это в настройках приложения; тогда оно считается приложением без ID. | Объявление и название записи. |
| v2RayTun, INCY, FlClashX, Koala Clash, Prizrak-Box, RenoarX, DeskBox | Да. | v2RayTun читает `X-Hwid-Limit`; остальные показывают название записи. |
| Shadowrocket, Karing, Clash Mi, Throne | Умеют, но по умолчанию выключено. | Название записи. |
| Hiddify, v2rayN, v2rayNG, Clash Verge Rev, FlClash, приложения sing-box, Passwall | Нет (на июль 2026; запросы на это открыты у v2rayN, Hiddify и Passwall). | Название записи. |
| Streisand, V2Box | Не подтверждено. | Название записи. |

- Сведения взяты из документации и исходников приложений и других панелей, а не из проверки каждого приложения, и новая версия может начать или перестать слать заголовок. Панель ориентируется на то, что приложение действительно шлёт: приложение без ID видно в карточке пользователя в строке **Приложения без ID устройства**.
- Человек с приложением без ID в режиме по умолчанию не остаётся за бортом: такие приложения делят одно место. В режиме **Строго** они не подключаются, а сообщение отправляет их к Happ или kl!ck.
- ID заглавными буквами (так шлёт INCY) или без дефисов (альтернативный ID Happ на компьютере) панель считает тем же устройством, что и обычный вид.

## Ссылки «добавить в одно касание»

Кнопка **Добавить** на странице пользователя открывает приложение с уже вставленной подпиской. Это собственная схема ссылок приложения, в которую подставлена ссылка подписки по **шаблону ссылки «добавить»** приложения (подстановки `{url}`, `{url_enc}`, `{name_enc}`: см. [Подписки](subscriptions.md)). Если шаблон пуст или приложение не поняло ссылку, страница предлагает **Скопировать ссылку**: её вставляют на экране добавления подписки в приложении.

Шаблоны известных приложений. Каждая схема подтверждена документацией или исходным кодом самого приложения, кроме схемы Happ (см. примечание ниже).

| Приложение | Платформы | Шаблон |
|:--|:--|:--|
| kl!ck | Windows, macOS | `klick://add?url={url_enc}&name={name_enc}` |
| Happ | iOS, Android, Windows, macOS | `happ://add/{url}` |
| Clash Verge Rev | Windows, macOS, Linux | `clash-verge://install-config?url={url_enc}&name={name_enc}` |
| FlClash | Android, Windows, macOS, Linux | `flclash://install-config?url={url_enc}` |
| Clash Meta for Android | Android | `clashmeta://install-config?url={url_enc}&name={name_enc}` |
| Hiddify | Android, iOS, Windows, macOS, Linux | `hiddify://import/{url}#{name_enc}` |
| v2rayNG | Android | `v2rayng://install-sub?url={url_enc}` |
| AmneziaVPN | все | нет: ключ на устройство, а не подписка |

- В собственной документации Happ схема `happ://add/` не описана. Её используют страницы подписок других панелей, и она же была в Mistgate по умолчанию. Если на телефоне кнопка ничего не делает, человек копирует ссылку.
- В выбор известных приложений не попали Streisand и Shadowrocket: их схемы не подтверждены (оставьте шаблон пустым, люди вставят ссылку сами). Не предлагается вовсе sing-box: он открывает только профиль sing-box в JSON, а Mistgate такой не отдаёт.
- Схему `clash://` занимают сразу несколько Clash-приложений, и система может открыть не то. Берите собственную схему приложения, как в таблице.

## kl!ck

[kl!ck](https://github.com/vbu00/klick) — десктопный клиент с открытым исходным кодом для Windows и macOS от vbu00, написан на Rust с Tauri вокруг неизменённого ядра Mihomo. Mistgate рекомендует его на компьютерах и называет автора: приложение не входит в Mistgate.

**Почему его рекомендуют на компьютере.** Оно читает Mihomo YAML — единственный формат, в котором есть все три протокола: человек с Hysteria2, VLESS и AmneziaWG получает все свои серверы одной подпиской в одном приложении, вместе с секцией DNS из своего пресета. Альтернатива на Windows и macOS — Happ для Hysteria2 и VLESS и AmneziaVPN для ключей: два приложения и два способа добавить.

**Что нужно в панели.** Ничего особенного: kl!ck скачивает подписку как `mihomo/1.19.31`, и правило по умолчанию `mihomo` отдаёт ему Mihomo YAML. Запись приложения — вида **По ссылке подписки**. Про серверы AmneziaWG см. переключатель выше. kl!ck шлёт ID устройства, поэтому каждый компьютер с kl!ck занимает в лимите устройств своё место.

**Скачать.** Страница релизов: <https://github.com/vbu00/klick/releases/latest>. Сборки для Windows и macOS выходят отдельно, а в именах файлов стоит версия, поэтому панель ссылается на страницу, а не на файл. На момент написания (октябрь 2026) последний релиз — 0.4.0 с установщиком для Windows; порт для macOS влит в исходники, и пакет для macOS появится на той же странице, когда его выпустят.

**Добавление в одно касание и его предел.** kl!ck обрабатывает `klick://add?url=<https-ссылка в percent-кодировке>&name=<необязательное название>` (а также `klick://add/<ссылка>`). Само оно ничего не добавляет: открывает свой экран **Добавить** с подставленной подпиской, показывает только домен ссылки, а человек подтверждает. Ссылка должна быть `https://`. Этот обработчик появился в kl!ck после 0.4.0, поэтому **для добавления в одно касание нужна сборка kl!ck новее 0.4.0**. Старые сборки схему не знают: человек копирует ссылку со страницы и добавляет её в kl!ck вручную.

## Настройка приложений в админке

**Подписки → Страница пользователя → Приложения на странице** — список карточек, которые показывает страница (см. [Подписки](subscriptions.md#приложения-на-странице)). Чтобы добавить приложение:

1. Под списком выберите **Платформу**.
2. Выберите **Известное приложение**: kl!ck, Happ, AmneziaVPN, Clash Verge Rev, FlClash, Clash Meta for Android, Hiddify или v2rayNG. В списке те приложения, что есть на этой платформе. **Своё приложение, заполнить вручную** оставляет прежний путь: вы выбираете вид (**Принимает**) и заполняете поля сами.
3. Нажмите **Добавить приложение**. Карточка заполнится названием, видом, ссылкой на скачивание для этой платформы и шаблоном ссылки «добавить». Любое поле можно поправить, добавить описание (80 символов), включить **Рекомендуем**.
4. Двигайте карточку стрелками: рекомендованное приложение идёт первым на своей платформе, а из равных — то, что выше в списке. Нажмите **Сохранить**.

Чтобы сделать kl!ck рекомендацией для компьютеров на уже работающей панели: добавьте его для Windows и для macOS, включите **Рекомендуем** и выключите его у Happ на этих двух платформах. Результат видно в предпросмотре на этой же вкладке.

## Свежая панель

Панель, которая ещё ни разу не сохраняла настройки подписки, показывает такие значения по умолчанию:

- Windows и macOS: сначала kl!ck, рекомендованный (страница релизов, `klick://add?url={url_enc}&name={name_enc}`), затем Happ.
- iOS и Android: Happ, рекомендованный, с `happ://add/{url}`.
- Все пять платформ: AmneziaVPN для ключей (на телефонах из магазина, на остальных — с сайта AmneziaVPN).
- Два правила, `mihomo` и `clash`, оба на Mihomo YAML.

Значения по умолчанию — это лишь то, что показывает панель без сохранённых настроек. Когда вы сохранили настройки, панель хранит ваш список ровно как сохранён: обновление его не переписывает.

## Через MCP

Агент с доступом «Оператор» и выше ведёт тот же список через `subscription_settings_get`, `subscription_app_upsert_plan` / `subscription_app_upsert_apply` и `subscription_app_remove_plan` / `subscription_app_remove_apply`. Каждое изменение страницы ждёт владельца: он одобряет его в **Интеграции → Ждут тебя**, а карточка показывает каждое поле полностью. Разобранный пример, как добавить kl!ck для Windows и macOS, есть в [MCP](../reference/mcp.md#пример-добавить-klck-для-windows-и-macos). Шаг есть и в промпте [руководства для ИИ-агентов](../getting-started/ai-agents.md).
