title: Первые пользователи

---

Подключение у человека заработает, когда есть четыре вещи: нода на связи, профиль на этой ноде, группа с этим профилем и пользователь в этой группе. Эта страница проходит по ним по порядку. Предполагается, что вы уже [добавили ноду](add-node.md) — вручную или [по SSH](ssh-install.md).

## Чек-лист первого запуска

Пока все четыре вещи не готовы, на «Обзоре» висит карточка **Первый запуск** с теми же шагами:

1. **Нода подключена**
2. **Профиль на ноде**
3. **Группа с профилями**
4. **Пользователь и ссылка**

Каждый шаг отмечается сам по тому, что уже есть в панели; вручную ничего отмечать не нужно. У невыполненного шага есть кнопка, которая ведёт к нему, а кнопка следующего шага выделена. Когда всё готово, карточка сворачивается в одну строку «Всё готово: нода, профиль, группа и пользователь», которую убирает кнопка **Скрыть** (только на этом устройстве).

## 1. Создайте профиль и поставьте его на ноду

Откройте **Профили → Новый профиль**. Начать можно и со страницы ноды: **Профили → Добавить профиль**.

1. **Протокол.** Выберите один:
   - **Hysteria2** — для приложений с подпиской: например, Happ или приложений на ядре mihomo вроде kl!ck, Clash Verge и FlClash. Одна ссылка несёт все серверы.
   - **AmneziaWG** — для AmneziaVPN. Каждое устройство получает собственный ключ. Приложения на ядре mihomo тоже получают эти серверы по подписке, если у человека включён AmneziaVPN.
2. **Название.** Пока вы его не ввели, оно следует за портом, например «Hysteria2 · 443».
3. **Настройки.** Для начала подойдут значения по умолчанию. У Hysteria2 посмотрите на одно поле:
   - **Сертификат: Let's Encrypt** (по умолчанию) требует домен, у которого A-запись указывает на ноду, и открытые на ней TCP 80 и 443. Берётся адрес ноды или **Домен (SNI)** из профиля, если вы его заполнили.
   - **Сертификат: Самоподписанный (с пином)** работает и с IP-адресом; приложение сверяет отпечаток сертификата, который приходит в подписке.

   Hysteria2 по умолчанию слушает UDP-порт 443 с обфускацией Salamander и сгенерированным паролем. Профиль AmneziaWG по умолчанию — версия 3.1 на случайном UDP-порту со сгенерированной обфускацией.
4. **Сразу после создания.** Этот блок внизу формы делает следующие шаги за один проход:
   - **Поставить на ноды**: ваша нода уже выбрана.
   - **Добавить в группы**: в новой панели отмечена группа «Все», потому что в ней ещё нет профиля этого протокола.
5. Нажмите **Создать профиль**. Панель ответит «Профиль создан и поставлен на 1 ноду».

Нода запускает сервер за несколько секунд. На её вкладке **Профили** видны порт, домен (SNI) и сертификат. Сертификат Let's Encrypt нода получает в фоне, и он появляется там со сроком действия, как только выдан.

Ещё до создания форма предупредит, если Let's Encrypt на выбранной ноде не сработает: «в адресе IP, Let's Encrypt там не сработает». Тогда выберите самоподписанный сертификат или впишите домен (SNI). Подробности: [Профили](../guide/profiles.md), [Hysteria2](../guide/hysteria2.md), [AmneziaWG](../guide/amneziawg.md).

## 2. Проверьте группу

Откройте **Пользователи → Группы**. Группу «Все» создал мастер первой настройки; если на шаге 1 вы оставили отметку, профиль уже в ней. Иначе откройте группу, отметьте профиль в списке **Профили в группе** и сохраните. То же самое делает **Где работает → Добавить в группу** на странице профиля.

Группа без профилей не даёт никакого доступа. Подробнее: [Пользователи и группы](../guide/users-and-groups.md).

## 3. Создайте пользователя

Откройте **Пользователи → Новый пользователь**:

| Поле | По умолчанию | Что значит |
|:--|:--|:--|
| Имя | | Как человек называется в админке, например «Алиса». |
| Группа | | Откуда человек получает профили. |
| Квота | 100 ГБ | Трафик в месяц, сброс 1-го числа. 0 — без лимита. |
| Срок | 30 дней | Потом доступ приостановится. 0 — бессрочно. |
| Устройства | 5 | Сколько устройств можно подключить. |
| Приложения в подписке | что даёт группа | Приложения с подпиской и AmneziaVPN, у каждого свой переключатель. Переключатель выключен, если в группе нет работающего сервера для этого приложения. |
| Все ноды | включено | Все ноды, включая те, что добавятся позже. Выключите, чтобы выбрать ноды. |
| Дополнительно → DNS | пресет группы | DNS-пресет только для этого пользователя. См. [DNS](../guide/dns.md). |

Нажмите **Создать**. Панель ответит «Алиса создан(а) · ссылка скопирована»: ссылка подписки уже в буфере обмена.

## 4. Отправьте ссылку

На странице пользователя есть кнопка **Ссылка подписки**. Она показывает ссылку и её QR-код, а также кнопки **Скопировать ссылку**, **Скопировать для отправки**, **Поделиться**, **Открыть страницу** и **Новая ссылка**. Отправьте ссылку в личном сообщении: по ней откроется страница с понятной инструкцией.

Что делает человек:

1. Открывает ссылку в браузере на том телефоне или компьютере, который хочет подключить. На его странице — инструкция для этой платформы, приложения, которые нужно поставить, кнопка, добавляющая подписку в приложение, QR-код для другого устройства, а также его трафик и срок. Для серверов, у которых вы указали пропускную способность канала в настройках ноды, страница ещё показывает, насколько занят канал каждого сервера («Низкая», «Средняя», «Высокая»).
2. **Приложение с подпиской:** ставит приложение и добавляет подписку кнопкой на странице или вставляет ссылку в приложение. Приложение забирает список серверов и потом само обновляет его по той же ссылке.
3. **AmneziaVPN:** создаёт ключ для устройства на той же странице, если в **Подписки → Страница пользователя** включены **Устройства на странице**, и импортирует его в AmneziaVPN. Если выключены, ключ создаёте вы в админке и отправляете человеку.

Если страница спрашивает пароль, значит включены пароли страниц: **Скопировать для отправки** кладёт ссылку и пароль в одно сообщение. Страница спрашивает пароль один раз на устройстве; приложениям он не нужен никогда.

Как понять, что всё работает:

- В списке **Устройства** у пользователя появляется устройство, как только приложение забрало ссылку (до этого там написано «Пока ни одного — появятся, когда друг откроет ссылку»).
- На странице ноды и на «Обзоре» человек виден онлайн, и начинает считаться трафик.
- Если окно ссылки пишет, что человек «пока ничего не получит», в его группе нет профиля, работающего на ноде, доступной этому человеку: вернитесь к шагам 1 и 2.

> **Важно:** **Новая ссылка** сразу заменяет старую; всем, у кого была старая, нужна новая. Делайте так, если ссылка ушла дальше, чем вы хотели, и удалите незнакомые устройства в списке **Устройства** у пользователя.
