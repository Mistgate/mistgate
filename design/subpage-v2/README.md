# Страница подписки Mistgate — редизайн v2: передача в разработку

Макеты новой публичной страницы подписки (`web/src/sub/*`). Задание — `brief/SPEC.md`, данные — `brief/DATA.md`, ссылки «добавить» — `brief/DEEPLINKS.md` (копии из пакета брифа). Этот пакет — **как это должно выглядеть**. Источник правды по поведению — SPEC; по виду — эти макеты.

> PNG-снимки экранов (screens/) в репозиторий не кладутся (15 МБ), они хранятся вне его; образец вида — файлы в html/.

## Что внутри

```
subpage-v2-design/
├── README.md        ← этот файл: карта экранов, решения, порядок работ
├── PROMPT.md        ← готовый промпт для Claude Code
├── mg-sub.css       ← все стили макетов: токены (тёмная/светлая, акцент) + компоненты. Основа для нового sub.css
├── html/            ← 27 экранов × 2 темы, статичный HTML (открывается без сети, кнопки не работают)
├── screens/         ← те же экраны PNG (телефон 2×, компьютер 1×)
├── assets/          ← значок Mistgate, перекрашенный под 4 акцента; QR-заглушки
├── fonts/           ← Onest + JetBrains Mono, те же подмножества, что встроены в страницу сейчас
└── brief/           ← SPEC.md, DATA.md, DEEPLINKS.md
```

HTML — это **не код для копирования в прод**, а точный образец вёрстки: отступы, размеры, порядок, тексты, классы. Разметку страницы по-прежнему строит `view.ts` / `amnezia.ts` через `h()`.

## Ключевые решения (что поменялось относительно текущей страницы)

1. **Один путь вместо двух карточек.** Было: «Подписка — Happ» и «Ключ AmneziaVPN» рядом, у каждой свои шаги и «Скачать». Стало: шаг 1 «Ваше устройство» → шаг 2 «Приложение» (карточки-радио, рекомендованное первым, остальные под «Другие приложения», не прячем) → шаг 3 «Как подключиться» под выбранное приложение.
2. **Выбор устройства — плитки с иконками** (телефон: 5 плиток 64×70, подпись 12 px; компьютер: «таблетки» с иконкой). Иконки — нейтральные (телефон/монитор/ноутбук/терминал), без логотипов ОС. Платформы без приложений не скрываем.
3. **Шаг 3 — «лестница»** из 2–3 пунктов с иконкой слева. Главная кнопка «Добавить одним нажатием» — одна акцентная на шаг. Запасной путь: на телефоне плашка «Не открывается? · Скопировать» + одна строка «куда вставить»; на компьютере — тихая ссылка «Не открывается? Скопировать ссылку» справа от кнопки.
4. **Статус** — карточка с приветствием и меткой состояния (точка + слово), под ней две плитки «Осталось» и «Трафик». Для проблемных состояний метка над приветствием, причина текстом, главная кнопка — «Написать в поддержку».
5. **Серверы** — карточка на сервер: флаг + страна · место, «работает / не отвечает», загрузка трёхсегментным индикатором (`null` → индикатора нет), чипы способов, «В приложении: DE · Hysteria2», строка DNS с «Изменить». Не отвечающий — пунктирный, в конце.
6. **DNS**: телефон — нижний лист; компьютер — модалка по центру. После выбора — уведомление прямо в карточке. Для ключей — блок «Обновите ключи на N устройствах» со строкой на каждое устройство и кнопкой «Обновить».
7. **Мои устройства** — одна карточка: строка «Приложения по ссылке» + строки ключей + «Добавить устройство». Счётчик мест — сегменты «2 из 3» в заголовке. Телефон: «Показать ключ» на всю ширину + «⋯» (Переименовать / Заменить ключ / Удалить). Компьютер: текстовые действия в строке.
8. **Шторки (bottom sheet) и диалоги**: шапка с иконкой-плиткой, заголовок, одна строка подписи, крестик. Выбор страны/варианта — одной строкой-«пикером». Шаги — в сером блоке. Служебное (ключ личный, версия AmneziaVPN) — мелкой строкой внизу. «Отмена» не дублируем — есть крестик.
9. **Тема**: переключатель «Авто · Светлая · Тёмная» в подвале (новое). Язык RU/EN остаётся в шапке.

## Токены и стили

`mg-sub.css` — готовый набор. Корень: `class="mg t-dark|t-light a-lavender|a-mint|a-sand|a-rose"`. В проде тема ставится классом/атрибутом на `<html>` (Авто = `prefers-color-scheme`), акцент — `--accent` из `brand.accent`, как сейчас.

- Существующие токены `sub.css` сохранены: `--bg --surface --surface-2 --border --text --muted --faint --accent --ink --warning --danger`, производные `--accent-soft/-line/-text` по той же формуле `color-mix(in oklch, …)`.
- **Новые токены**: `--raise` (выбранный сегмент: тёмная `#2c2c33`, светлая `#fff` + кольцо `--border`), `--track` (фон полос), `--warning-text`, `--danger-text`, `--ok-text`, тоны разделов `--tone-sky/-mint/-lav/-sand/-rose` и их `-bg` (значения из `tokens.json` дизайн-системы Mistgate), `--backdrop`, `--pop` (тень только у шторок/модалок в тёмной теме).
- Отступление от DS: `--danger-text` в светлой теме `#8f2427` вместо `#631e20` — чтобы «Удалить» читалось как красное (контраст ≥ 7:1).
- Радиусы: карточки 22 (компьютер 24), кнопки 14 (малые 12), поля 12, плитки 14, чипы 8–9, шторка 22 сверху.
- Кнопки: телефон 48, компьютер 44. Текст 15/14. Ничего важного мельче 13 на телефоне (исключение — подписи плиток устройств 12 px при иконке).
- Иконки — инлайн SVG, сетка 24, обводка 2.2, `currentColor`. Все пути есть в HTML; в коде — в `icons.ts`. Нужны новые: телефон-iPhone/Android, монитор, ноутбук, терминал, «другое», глобус (DNS), выход (запасной выход), обновить, карандаш, корзина, файл, глаз, питание, отправить, щит, QR, информация, предупреждение.
- **Флаги**: в макетах нарисованы CSS-градиентами (`.flag.de/.nl/.fi/.ru`) — только для макета. В проде — эмодзи, а на Windows (нет эмодзи-флагов) — `.cc` чип с кодом страны (см. `servers-01`).

## Порядок работ (предложение)

1. **Токены и база**: перенести токены и компоненты из `mg-sub.css` в `sub.css` (кнопки, плашки, чипы, точки/метки, плитки, `seg`, `plats`, `pick`, `steps-box`, `sheet`, `dlg`, `toast`). Тема Авто/Светлая/Тёмная (`localStorage["theme"]`).
2. **Статус + шапка + подвал** (все состояния SPEC 3.3, включая новые «скоро закончится» и «≥ 90 %»).
3. **Шаги 1–3** по новой схеме (устройство → приложение → как подключиться), запоминание платформы, «Готово — приложение получило подписку», первый/повторный визит (SPEC 6).
4. **Мои устройства**: строки, меню «⋯», переименование (`/devices/<id>/rename`), подтверждения в строке, шторки «Новое устройство» и «Ключ», устройства видны при неактивной подписке (DATA 2.6).
5. **Серверы** из `servers[]` (DATA 2.1) — пока поля нет на сервере, можно собрать из `server_loads`.
6. **DNS по серверам**: строка в карточке, лист/модалка, `POST <link>/dns`, уведомления и «Обновите ключи» (DATA 2.2–2.4). Открытый вопрос DATA 2.4 — вариант А.
7. Тесты (`*.test.ts`), снимки состояний (как `current/screenshots`), проверка контраста в обеих темах.

## Ограничения, которые нельзя нарушить (SPEC 12–13)

Один HTML-файл, CSP без внешних ресурсов; никаких чужих данных, скоростей, IP, внутренних имён узлов; ключ и ссылка целиком не выводятся (только копирование/QR); QR всегда тёмный на белом; состояние — всегда цвет + точка + слово; область касания ≥ 44; `prefers-reduced-motion`.
