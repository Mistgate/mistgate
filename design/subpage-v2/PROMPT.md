# Промпт для Claude Code

Положите папку `subpage-v2-design/` в репозиторий `mistgate-public` (например, в `design/subpage-v2/`) и отправьте Claude Code текст ниже. Работать лучше по этапам — после каждого этапа смотрите снимки и правьте.

---

Реализуй редизайн публичной страницы подписки (`web/src/sub/*`) по макетам в `design/subpage-v2/`.

Источники:
- `design/subpage-v2/README.md` — карта экранов, ключевые решения, токены, порядок работ. Прочитай целиком.
- `design/subpage-v2/brief/SPEC.md` — поведение, тексты, все состояния. `brief/DATA.md` — поля данных и новый вызов `/dns`.
- `design/subpage-v2/html/*.html` и `screens/*.png` — точный вид каждого экрана в тёмной и светлой теме. Сверяй отступы, размеры и тексты с ними.
- `design/subpage-v2/mg-sub.css` — токены и компоненты макетов; перенеси их в `web/src/sub/sub.css`, сохранив существующие токены.

Правила:
- Страница остаётся одним файлом без внешних ресурсов (CSP), разметка — через `h()` как сейчас, без фреймворков.
- Тексты — из SPEC и макетов, на «вы», RU и EN через `i18n.ts`.
- Состояние всегда «цвет + точка + слово», касания ≥ 44 px, `prefers-reduced-motion`, фокус виден.
- Флаги в макетах нарисованы CSS только для макета: в коде — эмодзи, на Windows — чип с кодом страны.
- Не выводи на страницу внутренние имена узлов, IP, адреса устройств, ключ и ссылку целиком.

Начни с этапа 1 из README («Токены и база») и этапа 2 («Статус + шапка + подвал»): обнови `sub.css`, `view.ts`, `i18n.ts`, добавь переключатель темы. Обнови тесты и сними скриншоты состояний dev-сервером (`?case=…`), как в `current/screenshots`, чтобы сравнить с `design/subpage-v2/screens`. Перед следующим этапом покажи, что получилось.
