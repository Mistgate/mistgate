Windows

Ключ для «Windows»

Настройте устройство сейчас. Закроете окно — устройство останется в списке, ключ можно будет показать снова.

Каждая страна — отдельное подключение. Добавьте одну; перестанет работать — добавьте другую.

mistgate-de.conf

Затем: AmneziaVPN → «+» → «Файл с настройками подключения»

На компьютере добавляйте файл, а не ключ — иначе соединение может не заработать.

Нужна AmneziaVPN 5.0.1.5 или новее

В ключе личные данные устройства — не пересылайте его.
