Overview

Resize a folder of pictures in one go

Mattepack resizes and compresses pictures in bulk. Point it at a folder and say how big you want the results; it does the rest and leaves the originals alone.

Version 0.5.0Licence MITPlatforms Linux, macOS, Windows
~/project
$ sudo apt install mattepack
$ mattepack --version
mattepack 0.5.0
$ mattepack photos --width 1600 --out small

Install

Mattepack is not shipped as a ready-made binary. Distributions package it, and building it from the source archive takes a few minutes.

$ sudo apt install mattepackDebian and Ubuntu
Fedorasudo dnf install mattepack
Arch Linuxsudo pacman -S mattepack
macOS with Homebrewbrew install mattepack

Get started

$ mattepack photos --width 1600 --out small
$ mattepack --help
$ mattepack --version

  • ChangedOutput files keep the original modification time.

0.3.217 August 2026

  • ChangedSmaller memory use when resizing very large pictures.
