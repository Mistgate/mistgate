Common questions

Do I need an account?

No. You can send files up to 2 GB without signing in.

How long does my link last?

Links work for 30 days. After that the file is deleted and the link stops working.

Can the recipient see my name?

Only if you tell them. The download page shows nothing about you.

What happens to my file once the link expires?

It is removed from storage. We do not keep a copy.
