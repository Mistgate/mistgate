Fieldwrangle

Select, sort and join CSV files

Fieldwrangle selects, sorts, joins and cleans CSV files from the command line. It handles large files without loading them into memory and never changes the input.

Quick start

shell
$ fieldwrangle select name,city people.csv
fieldwrangle sort --by city people.csv
Output
name,city
Mira,Leeds
Otto,York

What it does

  • Select and rename columns
  • Sort, filter and join files
  • Fix common problems such as stray quotes and mixed line endings

Installation

Fieldwrangle is a single executable with no dependencies.

  1. Download the archive that matches your system.
  2. Unpack it and copy the executable to a directory on your PATH.
  3. Run the version command to check that it works.
shellLinux
tar xf fieldwrangle-2.0-linux-amd64.tar.gz
sudo mv fieldwrangle /usr/local/bin/
fieldwrangle --version
If the version number is printed, the installation worked.

Usage

Pick columns

The select command prints only the columns you name, in the order you give them. A column can be renamed with an equals sign.

fieldwrangle select name,city people.csv
fieldwrangle select id,town=city people.csv

Filter rows

The filter command keeps the rows that match a simple condition. Several conditions can be combined.

fieldwrangle filter 'city = York' people.csv
fieldwrangle filter 'age > 30' people.csv

Join two files

The join command combines two files on a column they share. Rows without a match are dropped unless you ask for them.

fieldwrangle join --on id people.csv orders.csv

Options

Option Description
--delimiter Field separator. Default is a comma.
--header Set to false if the first row is data.
--output Write to a file instead of the screen.
--by Column to sort by.
--on Column to join on.

Frequently asked questions

How large a file can it handle?

Files are processed as a stream, so memory use stays small. Sorting large files uses temporary space on disk.

Does it change my files?

No. Output goes to the screen or to a new file.

What about other separators?

Use the delimiter option for tabs, semicolons or any single character.
