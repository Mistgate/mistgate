Overview

Resize a folder of pictures in one go

Grainbatch resizes and compresses pictures in bulk. Point it at a folder and say how big you want the results; it does the rest and leaves the originals alone.

Install

Grainbatch is not shipped as a ready-made binary. Distributions package it, and building it from the source archive takes a few minutes.

$ sudo apt install grainbatchDebian and Ubuntu
Fedorasudo dnf install grainbatch
Arch Linuxsudo pacman -S grainbatch
macOS with Homebrewbrew install grainbatch

Get started

$ grainbatch photos --width 1600 --out small
$ grainbatch --help
$ grainbatch --version
